## 생성 프롬프트 요약

용용이: 참고 이미지의 녹색 공룡만 분리. 입체감, 크림색 등 돌기, 주황빛 빨간 넥타이, 검은 눈과 웃는 표정, 손 흔드는 자세를 유지. 병아리·배경·하트·동작선을 제거. 잘린 머리·발·꼬리를 재구성하고 전신을 투명 배경 중앙에 배치.

삐약이: 오른쪽 아래 노란 병아리만 분리. 광택 있는 노란 몸, 검은 눈, 주황 부리와 발, 손 흔드는 자세를 유지. 공룡·배경·하트·동작선을 제거. 가려진 윤곽을 재구성하고 전신을 투명 배경 중앙에 배치.
