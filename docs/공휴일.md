# 연차 계산의 공휴일 제외

2026-10-26 확인. 대한민국 2026·2027년 공휴일과 대체공휴일을 js/workspace.js에 포함합니다. 인터넷 연결 없이 작동하며 외부 요청은 하지 않습니다. 노동절, 제헌절, 2026년 지방선거일을 포함합니다.

연차·반차·추가 사용 모두 토요일, 일요일 및 내장 공휴일에는 차감하지 않습니다. 여러 날을 선택하면 실제 평일만 계산합니다. 기존 휴가 기록은 변경하지 않고 현황을 열 때 사용·예정·잔여를 다시 계산합니다. 제외된 공휴일은 현황의 ‘공휴일로 차감 제외’에서 확인할 수 있습니다. 프로젝트 D-day는 달력상 남은 일수로 유지합니다.

자료가 없는 연도는 주말만 제외한 잠정치라는 경고를 표시합니다. 새로운 연도나 추후 정부가 지정한 임시공휴일은 공식 발표 확인 후 holidayData를 갱신해야 합니다. 연차 총수는 사용자가 입력하며 법정 연차 발생량을 산정하지 않습니다.
