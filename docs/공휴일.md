# 연차 계산의 공휴일 제외

2026-11-20 확인. 대한민국 2024~2030년 공휴일과 대체공휴일을 `source/js/calendar-data.js`에 포함합니다. 인터넷 연결 없이 작동하며 외부 요청은 하지 않습니다. 2026년부터 노동절·제헌절을 포함하고, 발표된 임시공휴일과 선거일도 반영합니다. 달력 표시와 연차 차감은 같은 자료를 사용합니다.

연차·반차·추가 사용 모두 토요일, 일요일 및 내장 공휴일에는 차감하지 않습니다. 여러 날을 선택하면 실제 평일만 계산합니다. 기존 휴가 기록은 변경하지 않고 현황을 열 때 사용·예정·잔여를 다시 계산합니다. 제외된 공휴일은 현황의 ‘공휴일로 차감 제외’에서 확인할 수 있습니다. 프로젝트 D-day는 달력상 남은 일수로 유지합니다.

자료가 없는 연도는 주말만 제외한 잠정치라는 경고를 표시합니다. 2028년은 한국천문연구원의 사전 달력자료, 2029~2030년은 음력 명절과 현행 공휴일·대체공휴일 규칙으로 구성한 예상 자료입니다. 미래의 임시공휴일, 선거 일정 변경, 법 개정은 확정 전에는 미리 알 수 없으므로 공식 발표 후 모듈을 갱신해야 합니다. 연차 자동 부여는 연차 정책 설정에서 적용하며 실제 근태 조건은 별도로 확인해야 합니다.
