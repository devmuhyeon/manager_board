# WorkLog KPI 설계 — 보유 데이터 기반 20개

2026-11-20 수정. 고객 원본 JSON에서 실제 읽을 수 있는 과업·담당자·파트별 상태·시작일·종료일·완료요청일만 사용합니다. 외부 사례를 흉내 낸 승인율·검수율·접근성 점수와 임의 목표 달성 판정은 제거했습니다. 기본 화면은 업무 데이터이며 개발 샘플은 별도로 전환합니다.

| 구분 | 지표 | 계산 |
|---|---|---|
| 공통 | 전체 과업 수 | 현재 원본 과업 ID 수 |
| 공통 | 배정된 담당 업무 수 | 담당자가 있는 과업·파트 조합 수 |
| 공통 | 담당자 미배정 과업 수 | 파트·공통 담당자가 모두 없는 과업 수 |
| 공통 | 전체 업무 완료율 | 완료·운영반영완료 업무 / 배정 업무 |
| 공통 | 기한 내 완료율 | 기한 내 완료 업무 / 종료일·기한이 확인되는 완료 업무 |
| 공통 | 평균 완료 소요일 | 완료 업무의 종료일−시작일+1 평균, 달력일 |
| 공통 | 마감 초과 미완료율 | 기한 경과 미완료 / 기한 있는 미완료 |
| 공통 | 완료 후 수정 업무 비율 | 현재 완료 후 수정 / 배정 업무 |
| 기획 | 배정 업무 수 | 담당자가 있는 기획 업무 |
| 기획 | 업무 완료율 | 기획 완료 / 기획 배정 업무 |
| 기획 | 3일 내 마감 업무 수 | 오늘~3일 뒤 마감인 미완료 기획 업무 |
| 기획 | 수정 진행 업무 수 | 현재 완료 후 수정인 기획 업무 |
| 디자인 | 배정 업무 수 | 담당자가 있는 디자인 업무 |
| 디자인 | 업무 완료율 | 디자인 완료 / 디자인 배정 업무 |
| 디자인 | 3일 내 마감 업무 수 | 오늘~3일 뒤 마감인 미완료 디자인 업무 |
| 디자인 | 수정 진행 업무 수 | 현재 완료 후 수정인 디자인 업무 |
| 퍼블리싱 | 배정 업무 수 | 담당자가 있는 퍼블 업무 |
| 퍼블리싱 | 업무 완료율 | 퍼블 완료 / 퍼블 배정 업무 |
| 퍼블리싱 | 3일 내 마감 업무 수 | 오늘~3일 뒤 마감인 미완료 퍼블 업무 |
| 퍼블리싱 | 수정 진행 업무 수 | 현재 완료 후 수정인 퍼블 업무 |

- 비율은 모두 ×100, 소수 첫째 자리까지 표시합니다. 분모가 0이면 집계 대기, 건수는 기록이 없으면 0건입니다.
- 공동 담당자가 여러 명이어도 한 과업·파트는 한 건입니다. 원본에서 제거된 과업과 중복 과업 ID는 제외합니다.
- 완료 후 수정은 미완료로 봅니다. 마감 위험 지표는 보류·접수 업무도 포함합니다. 누적 수정 횟수나 과거 승인 결과를 상태만 보고 추정하지 않습니다.
- 파트별 `담당자_기획/디자인/퍼블`, `상태_파트`를 사용합니다. 역할을 알 수 없는 공통 담당자는 미배정 과업 판단에만 사용합니다.
- `작업시작일_파트`, `시작일_파트`, `작업종료일_파트`, `완료일_파트` 또는 작업내용의 `작업시작일자: YYYY-MM-DD`, `작업종료일자: YYYY-MM-DD`를 읽습니다. 마감은 파트별 완료요청일·마감일 또는 과업 완료요청일입니다.
- 유효하지 않은 날짜·미래 완료일·시작보다 이른 완료일은 기간 집계에서 제외합니다. 관측 시각·최초 수집 시각을 실제 작업일로 대체하지 않습니다. 기한 내 완료율과 소요일에 포함된 실제 집계 건수를 카드에 표시합니다.
- 현재 원본 스냅샷 기반입니다. 기간별 생산량·최초 승인율·검수 통과율·접근성 점수는 해당 이력·검수 데이터가 없으므로 산출하지 않습니다.
- 화면·산식은 `source/html/reports/kpi-dashboard.js`, 개발 샘플은 `test/kpi-samples.js`에서 분리 관리합니다. 샘플 수치는 동일 산식으로만 계산하며 실제 데이터·저장 파일에 섞지 않습니다.
