# 기능별 화면·저장 구조

시작 파일은 루트 `index.html`과 `source/html/index.html`입니다. 실행 위치에 맞춰 모든 리소스를 절대 URL로 계산하며 내부망·하위 경로·로컬 파일 실행을 함께 지원합니다.

화면의 HTML 문자열은 아래 각 `page.js` 또는 `views.js`에서 관리합니다. 단순 화면·폼 배치를 바꿀 때 공통 앱을 수정하지 않습니다.

|---|---|---|
| 홈 | `source/html/home/page.js` | `source/js/briefing-*.js`, `source/css/briefing-*.css` |
| 오류개선 | `source/html/work/error-improvements/page.js` | 공통 카드 스타일 |
| 퍼블리싱 문서 | `source/html/work/publishing-docs/page.js`, `model.js` | 같은 폴더의 `style.css` |
| 업무관리 | `source/html/work/page.js` | `source/js/task-board.js`, `source/css/task-board.css` |

게시판의 배치·댓글 UI는 게시판 폴더에서만 변경합니다. 업무 데이터 모델, 권한 규칙, 저장 계약 자체를 바꾸는 기능은 공통 데이터 검증 또는 공통 이벤트 연결도 함께 수정해야 합니다. `source/js/app.js`는 로그인 상태, 공통 이벤트, 화면 모듈 연결을 담당합니다. `source/html/pages.js`는 테스트용 모듈 진입점이며 브라우저는 각 기능 파일을 직접 로드합니다. 공통 색상·버튼·서체는 공통 에셋으로 유지합니다.

## 공유 저장 폴더

- `process/commits/<UUID>.json`: 마지막에 발행하는 변경 불가능한 저장 목록. 충돌 판단 기준입니다.
- `save/toys/<UUID>.json`: 투표·끝말잇기·돌림판 내역입니다. 내용 저장으로 공유하며 공용 저장의 충돌 감지를 그대로 적용합니다.
- `save/work`, `save/people`, `save/cards`, `save/settings`, `save/assets`: 기능별 JSON 이력입니다. 변경 없는 모듈은 파일을 재사용합니다.
- `save/users/<이름>/<UUID>.json`: 개인 메모·일정입니다.
- `save/게시판/<UUID>.json`: 글별 본문·댓글입니다.
- `save/게시판/첨부/<UUID>.json`: 첨부별 파일명·형식·크기·내용 에셋입니다. 본문 JSON에는 에셋 참조만 남기며 다시 읽을 때 복원합니다.
- `save/휴가/<시작연도>/<UUID>.json`: 해당 연도에 시작한 휴가 기록 및 개인별 총수 설정입니다.
- `save/휴가/설정/<UUID>.json`: 휴가 유형·표시 순서·연차 정책입니다.

기존 `process/<기능>` 및 이전 `save` 이력은 계속 읽습니다. 다음 저장부터 새 구조를 사용하며 기존 파일을 이동·수정·삭제하지 않습니다. 개인 생일·입사일은 인원 모듈에, 정책별 입사일은 휴가 설정에 포함됩니다. 전체 백업에는 공유 저장 폴더의 **process와 save를 함께** 포함해야 합니다. 파일 일부만 옮기면 저장 목록의 참조가 끊깁니다.

동시 저장 검사와 마지막 저장 목록 발행 순서는 유지합니다. 고객 원본 JSON은 모든 경로에서 읽기 전용입니다. 복구 도구는 이전·현재 구조, 휴가 연도별 설정, 게시판 첨부를 모두 복원합니다.

첨부파일은 파일당 20MB·글당 최대 10개·합계 40MB입니다. 댓글·답글은 이미지만 지원합니다. 브라우저의 작은 임시 저장 공간을 초과하면 IndexedDB로 임시 보관하고, 공용 반영은 내용 저장으로 완료합니다. SVG·HTML·실행 파일은 첨부 대상에서 제외합니다.

## 연차·공휴일·카드

입사일을 등록하면 연차 사용기간은 입사 기념일부터 다음 기념일 전날까지입니다. 입사일이 없으면 기존 연도별 직접 설정을 유지하고 달력 연도를 임시 기준으로 표시합니다. 1년 미만은 매월 개근 시 1일 또는 연간 선부여를 선택할 수 있으며, 선부여도 월별 법정 발생량보다 적게 계산하지 않습니다. 실제 출근율·개근 여부는 이 프로그램이 판정하지 않으므로 예외는 관리자가 확인해야 합니다.

법인카드는 카드 설정에서 적용 월과 ‘잔여금액 다음 달 누적’을 정합니다. 끄면 매달 기본금액으로 초기화하고, 켜면 전월 잔여금액에 이번 달 기본·추가금액을 더합니다. 설정 이전 월의 계산 방식은 보존합니다.

공휴일은 `source/js/calendar-data.js`에서 공통 관리합니다. 미래 자료의 확정 여부와 공식 출처는 [공휴일.md](공휴일.md)를 확인하세요.
