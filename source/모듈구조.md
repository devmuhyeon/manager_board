# 모듈과 에셋 관리

HTML은 진입 문서, JS는 기능별 모듈, source는 스타일·문서, images는 이미지, font는 로컬 서체입니다. 외부 CDN에 의존하지 않습니다.

| 파일 | 역할 |
| --- | --- |
| js/core.js | 데이터 가져오기·검증·과업 필터 |
| js/personnel.js | 인원·역할·전체관리자 이전·개인 일정 |
| js/workspace.js | 분류·수정작업·연차와 공휴일 계산 |
| js/team-board.js | 팀 게시판 조회·작성·편집·삭제 권한 |
| js/navigation.js | 메뉴 구조·화면 제목·팀 표시명·바로가기 검증 |
| js/detail-views.js | 휴가 표·오늘 일정·게시판 화면 구성 |
| js/work-tables.js | 과업별·담당업무별 표, 날짜·상태·접이식 메모 |
| source/work-tables.css | 공통 업무 표와 필터의 디자인 |
| js/app.js | 로그인·연결·상태·모듈 연결과 이벤트 처리, 기존 화면 |
| js/local-vault.js | 브라우저별 로그인·연결 기억 |
| js/design-mockups.js | 운영 상태와 분리한 10개 디자인 목업 |
| source/theme.css | 사용자 지정 색상과 기본 테마 |
| source/components.css | 새 메뉴·표·게시판 공통 컴포넌트 |
| source/design-mockups.css | 비교용 시안 스타일 |
| font/PretendardVariable.woff2 | 본문 로컬 서체 |
| font/tossface/ | 공식 배포 원본 이모지 폰트와 라이선스 |

기존 app.js 전체를 분해한 것은 아니며, 새 주요 기능은 독립 모듈로 추가했습니다. 기존 동작을 유지하면서 이후 수정 시 화면 단위로 분리합니다. 기존 JSON의 ‘퍼블’ 키와 원본 필드명은 호환성을 위해 유지하고 화면·내보내기에는 ‘퍼블리싱’으로 표시합니다.

## 2026-10-27 반영

- 팀 게시판: 팀별 조회·작성, 작성자 본인/소속 팀장/관리자 편집 및 삭제, 상단 고정. 통합관리 JSON의 teamPosts에 저장.
- 휴가 상세: 팀/이름/직급/연차구분/연차 기간/편집. 상세에서는 D-day 제거, 홈 요약은 유지.
- 일정관리: 오늘/주간/마감/휴가. 업무 관리: 과업별/수정사항/사용자별/고객별/주간보고.
- 날짜에 연도 포함. 표 행 간격·헤더·테두리·가로 스크롤 개선.
- 전체관리자 이전: 현재 전체관리자만 설정 가능. 이전 후 기존 전체관리자·팀관리자 권한 해제, 팀장 지정 유지. 내용 저장 후 공용 파일 반영. 전체관리자는 이전하기 전 퇴사 처리 불가.
- 상단은 한 줄만 사용. 사이트 바로가기를 제거하고 원본·저장 연결 상태와 재연결을 표시.
- 목업 10개를 html/design-mockups.html에 제공. 선택은 목업 전용 브라우저 저장소에 표시하며 실제 테마를 바꾸지 않음.

## 자료 대기

‘운영총괄팀 콘텐츠 기획 및 디자인 위탁 수행과제 진행 현황’ 구글 시트는 아직 제공받지 않았습니다. 현재 표 정리는 기존 스크린샷·데이터를 기준으로 했으며, 해당 시트를 반영한 진행현황 재구성은 자료 수신 후 진행해야 합니다.

## 2026-10-29 전체 스타일 개편

source/workplace-design.css에 네이비 사이드바, 공통 카드·표·폼·로그인·다크 모드 스타일을 모았습니다. 색상은 기존 루트 팔레트를 사용합니다. single-topbar.css를 마지막에 불러 한 줄 상단바 규칙을 유지합니다. 목업 01번에 같은 스타일을 반영했습니다.

## 2026-10-30 화면 스타일

- `js/display-styles.js`: 공통 10개 스타일 목록, 기본 팀 브리핑, 브라우저별 선택 기억, 홈 구성과 단일 상단 메뉴 배치.
- `source/display-styles.css`: 스타일 선택 카드와 실제 10개 화면 스타일. `single-topbar.css`는 마지막에 읽어 한 줄 상단바를 유지.
- 상단 설정의 화면 스타일 또는 디자인 비교 화면의 적용 버튼에서 선택. `workplace-style`에 저장하며 같은 출처의 다른 창에도 반영.
- 팀 브리핑은 본인 팀 게시글·전체공지, 미완료 과업과 주간 일정을 함께 표시. 빈 게시판에만 캐릭터 안내를 표시.
- 칸반은 실제 과업 상태별, 타임라인은 월~일 과업 마감별로 표시하며 과업명으로 기존 편집 화면을 연다.
- 기존 개인 홈 배치와 업무 데이터는 스타일 전환 시 변경하지 않음. 팀 브리핑은 소식·업무·주간 일정을 우선 배치하고 나머지 카드는 저장된 개인 순서를 사용.
- 미드나이트는 다크 화면을 강제하고 다른 스타일로 전환하면 기존 밝기 설정을 복원.

## 2026-10-30 공통 여백 정리

- `source/layout-spacing.css`: 모든 스타일의 공통 간격. 바깥 32px(중간 24px/모바일 16px), 카드 안쪽 24px(모바일 16px), 섹션 위아래 16px, 카드 사이 24px(모바일 16px), 작은 항목 사이 8px.
- 본문·설정·팀 브리핑·일정·메모·게시판·표·모달·로그인에 같은 여백 변수를 적용. 컴팩트 표의 행 세로 간격만 12px로 유지.
- 좌측 메뉴와 상단 메뉴 팝업은 스크롤 동작을 유지하면서 스크롤바를 숨김.
- 표의 고정 스크롤바 여백을 제거하고 컨테이너·머리글·본문·빈 셀까지 배경색을 지정해 끝부분의 빈 색상을 방지.
- 한 줄 상단바 스타일은 항상 마지막에 로드.

## 2026-10-30 공통 컴포넌트 규칙

- `source/ui-system.css`: 모든 스타일과 비교 화면의 버튼, 텍스트 위계, 중성색 구분선, 스크롤바를 공통 관리.
- 장식용 유색 border를 제거하고 테마별 `--border` 한 가지를 사용. 상태는 배경·문구로, 선택은 배경·체크로 구분.
- 페이지·카드 제목 아래에 1px 구분선 사용. 중첩 카드, 제목 바로 아래 표, 연속된 표 행은 맞닿는 선을 한쪽에서만 표시.
- 버튼은 기본/주요/텍스트/탭 역할별로 통일. 기본 조작 버튼 높이 36px, 모서리 8px.
- 제목 28px(모바일 24px), 섹션 16px, 소제목 14px, 본문 13px, 보조정보 12px.
- 표·일정·메모·칸반·타임라인·모달·상단바의 스크롤바는 얇은 중성색 트랙과 둥근 손잡이, hover 상태를 공통 적용. 좌측 메뉴 스크롤바는 계속 숨김.
- 별도 폴더 아이콘·pending-dot은 렌더하지 않음. 원본·저장 상태 버튼 각각에서 연결 관리 창을 열며, 저장 전 변경사항은 내용 저장 버튼에 표시.
